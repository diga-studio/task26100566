# orgtree

进程内的下线组织树组件（Go 库），支持并发安全地迁移整棵下线子树，并按层查询团队成员。

## 接口

```go
// 根据「分销商ID -> 直属上级ID」构造组织树。
// 根节点的上级 ID 为不在键集合中的值（如 0）。
// 输入保证是合法单根树；初始化后节点集合固定。
func New(records map[int64]int64) *Tree

// 将 member 及其全部下线迁到 newParent 下，子树内部关系不变。
// 返回是否成功：
//   - 根节点不可迁移，返回 false；
//   - newParent 处于 member 子树内（含 member 自身）时拒绝，返回 false；
//   - newParent 已是当前上级时视为成功的无操作，返回 true。
// 失败的迁移不留下任何关系变化。
func (t *Tree) Move(member, newParent int64) bool

// 返回 member 以下第 1~10 层的成员 ID 分组（不含 member）。
// 下标 i 对应第 i+1 层；不足 10 层时只返回实际存在的层。
func (t *Tree) Team(member int64) [][]int64
```

## 并发语义

- 所有 `Move` / `Team` 在内部读写锁保护下原子生效，满足可线性化：
  每个已完成的调用都可解释为在调用与返回之间某一时刻原子发生，并遵守调用的先后关系。
- 查询只会看到迁移前或迁移后的完整结构，不会观察到中间态。
- 环检测沿上级链走到根（树深可超过 10 层），任何可观察状态始终是
  连通、无环、每个非根节点恰有一个上级的树。

## 测试

```sh
go test -race ./...
```

覆盖：并发 `Move(A,B)` 与 `Move(B,A)` 恰有一次成功；并发跨分支 `Move` 与
`Team` 时查询结果始终对应某个合法快照（无重复、无消失、无层级混杂）；
以及深度上限、深层环检测、拒绝迁移无副作用等基础场景。
